## Git 
### 注意事项
里面有个注意的点是注意分支中的merge(合并)和rebase(变基), 
在个人分支中需要主分支中别人更新的内容时, 
可以使用rebase来在自己开发的分支中加入新功能, 而在自己的功能分支完成后, 就可以把自己的分支与主分支进行merge.
切记不可以在**主分支rebase!!!**, 否则会覆盖掉之前主分支的所有更新记录.

## 完整调参流程

### 前置准备

```
1. 确认角度传感器正常：
   看串口 ANGLE 值，手动推摆杆，值应该明显变化（不是 0~1 度跳动）

2. 确认电机正常：
   S:100   → 电机正转
   P       → 停
   S:-100  → 电机反转
   P       → 停

3. 确认编码器正常：
   手动推平台，ENCODER 值应该变化
```

---

### 第一阶段：校准（5 分钟）

```
串口操作：
N:xxx       ← 设竖直角度（先估一个值，比如 180）
C:001       ← 校准限位
            ← 串口会打印：CALIB: right=xxx, left=xxx, center=xxx

校准后手动把摆杆摆到竖直位置，看 ANGLE 值
假设看到 ANGLE=175.3
→ 发 N:175.3  ← 精确校准竖直角度
```

---

### 第二阶段：只调角速度环（最内环，10 分钟）

```
关掉外环：
E:0,0,0
F:0,0,0

给角速度环初始参数：
G:5.0,2.0,0.5

开数据流看 θ̇：
D:1
```

**操作：用手轻拨摆杆，松手，看 θ̇ 波形**

```
理想 θ̇ 波形：
  0.5 │  ╱╲
      │ ╱  ╲
  0.0 │╱────╲──────  ← 0.1s 内回 0
      └──────────── time

θ̇ 不收敛（来回晃）→ 减 Kp：
G:3.0,2.0,0.5

θ̇ 收敛太慢（好久才停）→ 加 Kp：
G:8.0,2.0,0.5

θ̇ 有毛刺（高频抖动）→ 减 Kd：
G:5.0,2.0,0.2

θ̇ 回不到 0（有偏移）→ 加 Ki：
G:5.0,4.0,0.5
```

**调好的标志：拨一下，0.1s 内 θ̇ 回到 0，不振荡，不抖动**

---

### 第三阶段：加角度环（中间环，15 分钟）

```
用调好的内环参数不动

给角度环初始参数：
F:3.0,3.0,0.3

开数据流看 θ：
D:1
```

**操作：用手把摆杆拨偏 5°~10°，松手，看 θ 波形**

```
理想 θ 波形：
  0.1 │  ╱╲
      │ ╱  ╲
  0.0 │╱────╲──────  ← 0.3s 内回 0，1~2 次振荡
      └──────────── time

θ 振荡不收敛（一直晃）→ 减 F 的 Kp：
F:1.5,3.0,0.3

θ 收敛太慢 → 加 F 的 Kp 或 Kd：
F:5.0,3.0,0.5

θ 有静差（停在 0.05 rad 不回 0）→ 加 F 的 Ki：
F:3.0,5.0,0.3

θ 超调太大（回过头）→ 减 F 的 Kp 或加 Kd：
F:2.0,3.0,0.5
```

**调好的标志：拨偏 10°，0.5s 内 θ 回到 0，1~2 次振荡收敛**

---

### 第四阶段：加位移环（最外环，15 分钟）

```
用调好的内环、中环参数不动

给位移环初始参数：
E:2.0,0.1,1.0

开数据流看 x 和 θ：
D:1
```

**操作：把平台推偏 3~5cm，松手，看 x 和 θ 波形**

```
理想 x 波形：
  0.05│  ╱╲
      │ ╱  ╲
  0.0 │╱────╲──────  ← 2~3s 内回 0，摆杆全程不倒
      └──────────── time

x 回不去（停在错误位置）→ 加 E 的 Kp：
E:4.0,0.1,1.0

x 回去了但摆杆倒了（θ 发散）→ 减 E 的 Kp：
E:1.0,0.1,1.0

x 回去时摆杆大幅晃动 → 减 E 的 Kp 或加 E 的 Kd：
E:2.0,0.1,2.0

x 回去太慢 → 加 E 的 Kp：
E:3.0,0.1,1.0
```

**调好的标志：推平台 ±5cm，2~3s 内 x 回到 0，摆杆全程不倒**

---

### 第五阶段：综合测试（10 分钟）

```
关数据流：
D:0

测试 1：手推摆杆 ±10°
  → 1s 内恢复 ✅

测试 2：手推平台 ±5cm
  → 3s 内回中，摆杆不倒 ✅

测试 3：轻拍底座
  → 摆杆不倒 ✅

测试 4：长时间运行（5 分钟）
  → 摆杆持续稳定 ✅
```
